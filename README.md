# AI-Based Loan Eligibility Prediction System

## 📌 Overview
This project is a web-based application that predicts loan eligibility using
machine learning. The application is built using Python and Streamlit.

## 🚀 Features
- AI-based loan approval prediction
- Rule + ML hybrid decision system
- Simple and user-friendly web interface
- Real-time eligibility results

## 🧠 Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas, NumPy

## 🖥️ How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
